# Picture Talk PECS v2

PTP | Picture Talk PECS v2 開発管理

特別支援学校で、カードを選び、並べた言葉を音声で伝える学習を支えるWebアプリ。
旧 [Picture-Talk-PECS](https://github.com/kamekamelab/Picture-Talk-PECS) とは独立して開発します。

## 現在の範囲（0.7.0）

- Phase 1：カードを選ぶ → その場で読み上げる
- Phase 2：1枚のカードで自分から伝える画面。端末・相手との距離や場所は先生が調整
- Phase 3：先生が指定した2枚以上から選ぶ画面。自動の正誤判定なし
- Phase 4の基本：ことばのカードを並べ、最後に「ください」を置く日本語のSentence Strip。カードを触ってブックへ戻す操作・選び直し、文の読み上げ、語順を保持した記録
- Phase 5：「なにがほしいですか？」の質問に対して、日本語の要求文を作って読み上げる
- Phase 6：見える・聞こえる・持っていることを文末カードで伝える。質問への応答／質問なしの設定
- 文の帯は濃いオレンジ色の台紙とマジックテープ。横の「よむ」で日本語順に読み上げ、「とめる」で停止、「↶ ひとつもどす」で直前の操作を取り消す
- 写真・イラスト・文字・マーク・カテゴリのカード編集。文字は上／下、文字と写真のバランスは3種類
- A4印刷：カードを選択し、4.5／3.5／2.5cm角の3サイズで自動改ページ。紙とデジタルで同じ画像・文字配置を使用
- 先生用画面と生徒用画面の分離、長押しと任意のPIN
- 読み上げ完了ごとの日時・カード・呼び名・支援の有無の記録、CSV出力
- IndexedDBによる保存、JSONバックアップと内容確認付き復元
- Service Workerによるオフライン起動、ホーム画面追加用PWA

**ドラッグ、要求表現の編集、Phase 2の距離・場所の詳細記録、Phase 3のカテゴリ・自由配置は未実装です。** Phase 4は「ください」の文をタップで作る基本機能に限ります。[確認済み仕様](docs/DECISIONS.md)と[開発計画](docs/ROADMAP.md)を参照。
PECSの考え方を参考にした教育用アプリで、正式な研修や個別の指導計画を置き換えるものではありません。特にPhase 1・2では紙カードによる実際の交換との併用を想定します。

## ローカル起動

Node.js 22以降。外部パッケージのインストールは不要です。

このMacでは [scripts/dev.command](scripts/dev.command) を実行すると、同梱Nodeを検出して起動できます。ターミナルからは `./scripts/dev.command`。

```sh
npm run dev
```

http://127.0.0.1:4175/ を開きます。停止はCtrl+C。
`node` がPATHにない場合は、Codexの同梱Nodeの絶対パスで `scripts/serve.mjs` を実行できます。
対応ブラウザーはWeb Locks・IndexedDB・Service Worker・dialog・createImageBitmapに対応した新しいSafari / Chromeです。

```sh
npm run check
```

このMacの同梱Nodeにはnpmがないため、検証は同梱Nodeの絶対パスで `--test tests/*.test.mjs` と `--check dist/app.js` 等を実行します。

保存形式はv5です。旧版のv1・v2・v3・v4データ／バックアップを引き継ぎます。過去の交換記録はそのまま保持し、新しい読み上げ記録と区別します。新版で保存したデータは0.6.0以前の版では開けません。更新前のバックアップを保持してください。

## 読み上げ

文づくり画面で完成した文の「よむ」を押すと読み上げます。カード1枚を選ぶ画面でも同じように読めます。渡す・受け取り確認の画面はありません。先生用設定で、カードを選んだ直後の名称読み上げをオンにできます（初期値オフ）。日本語の語順を保ち、1つの音声として読みます。再生中の再押下、文の変更・取消、別画面への移動、画面を隠したときは停止します。最後まで読み上げると「読み上げ」種別の学習記録が1件残ります。途中停止・エラー・先生用の試聴・選択時の名称読み上げでは件数を増やしません。確認や評価の入力を求めず、カードを画面に残します。

0.6.0ではことばの間をあける読み方を初期値に戻しました。「ボール、ください」のように読点を入れ、オフでは「ボールください」とつなげます。休止の長さは端末の音声エンジンによって異なります。語順・言葉は変えず、助詞は自動追加しません。話す速さは既存の設定を保ちます（初期値1.0）。先生用の「設定 → 読み上げ」で、声・速さ・間・選択時の読み上げを試聴・保存できます。

端末に準備された日本語音声を使います。Web Speech APIの `localService === true` を確認し、クラウド・言語違い・未判定の音声には渡しません。利用可能な音声がない場合は先生用設定に案内を表示します。端末に日本語音声を準備してから、機内モードでの動作も確認してください。実際の発音・音量は端末の音声設定に依存します。

帯のカードをタップするとブックへ戻ります。カード下の×と左右矢印は表示しません。「↶ ひとつもどす」で直前の追加・カードを戻す操作を取り消せます。誤って戻したカードは元の位置へ復元されます。学習記録は取り消しません。履歴は現在の学習中の直近100操作までで、再起動・学習の開始でリセットされます。

カードの移動先が画面内に見えているときは、貼る／戻す動きを表示します。動きを減らす端末設定が有効な場合はアニメーションを省きます。

## A4での印刷

先生用の「カード」で画像・文字・文字位置・大きさを編集して保存し、「印刷」でカードとサイズを選びます。中3.5cmが初期値。A4縦・余白10mm・カード間3mm、枠は切り取り線として使えます。印刷設定はA4、倍率100%（実際のサイズ）、ヘッダー・フッターなし。用紙に合わせる自動縮小は使わず、初回は定規で寸法を確認してください。実際のプリンター・iPadでの印刷は未確認です。

## 保存とプライバシー

- 写真・記録はこの端末・ブラウザー・配信元のIndexedDB内。自動同期や外部解析はありません。
- 画像は端末内で最大800pxに縮小・PNG化し、位置情報等のメタデータを除去。大きいPNGは白背景のJPEGに変換します。JPEG・PNG・WebP・GIF（静止画）を受け付けます。
- データ総量は24MBまで、復元ファイルは25MBまで。常に復元できるバックアップを書き出せるように上限を設けています。
- 実名は不要。任意の呼び名を使用します。初期版は1つの学習設定を切り替える構成です。
- PINは誤操作防止です。暗号化・厳密な本人認証ではありません。再起動後もPINが必要です。
- ブラウザーデータ削除・端末故障に備えてバックアップを保存してください。ファイルは暗号化されません。
- PINを忘れた場合は、PINが分かるバックアップまたはPIN設定前のバックアップを別のブラウザー環境に復元してください。データの削除は復旧策ではありません。
- 同時に複数のタブで開けないようWeb Locksを使用し、古い状態での上書きを防ぎます。
- インターネット利用時にはアプリ配信元への通信が発生します。GitHub Pages公開時はGitHubによるIPログがあります。
- 実際の児童生徒データをGit、Issue、PRに登録しないでください。

## オフラインと更新

初回の読み込み完了後、「オフライン準備済み」を確認します。カード画像はIndexedDB、プログラム類は専用キャッシュに保存します。新しいバージョンは開いている画面を強制更新せず、すべてのタブを閉じて開き直すと適用されます。更新時は `dist/sw.js` のキャッシュ名も変更してください。

ローカルPCのlocalhostはiPadから開けません。iPad実機では、後の公開工程でGitHub Pages等のHTTPS配信先を用意して検証します。通常のLAN内HTTP配信ではPWAの検証はできません。

## GitHub Pages（未公開）

`dist/` 以下をそのまま配信できる静的構成です。サーバーDBやAPIは不要です。
公開工程でGitHub Actionsによる `dist/` のアップロードとPagesへのデプロイを追加する予定です。
アセット・Service Worker・manifestは相対URLで、リポジトリ配下のURLに対応しています。
初期版ではPagesを有効化していません。

## フェイズ5・6の使い方

学習の準備でPhase 5または6を選びます。Phase 5は先生が「なにがほしいですか？」と問いかけ、生徒は「ボール＋ください」などを作ります。Phase 6は学習方法で「質問なし」「みえる」「きこえる」「もっている」を選択。「ボール＋がみえます」「おんがく＋がきこえます」「ボール＋をもっています」のように日本語の文末へ置きます。

文末を先に選んでも、物のカードはその前に入ります。タップで戻す・ひとつもどす・選択時の名称読み上げ・全文の読み上げに対応。質問は画面に表示し、先生が問いかけます。アプリから質問を自動再生しません。記録・CSV・バックアップには当時の文と質問／質問なしの設定を残します。「自分からのコメント」は選択した学習方法であり、自発性の達成判定ではありません。支援の有無は先生が評価します。
