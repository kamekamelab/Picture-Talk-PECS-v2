# PTP v2 設計と初期版の範囲

## 方針

既存の Picture-Talk-PECS を変更しない独立したリポジトリ。画面・コード・保存領域を分離する。現行の操作は「カードを選ぶ・文を並べる → よむ」。アプリ内の渡す・受け取り確認は設けない。読み上げ完了は使用記録として残し、実際の交換成立や学習段階の達成を自動判定しない。

## 画面

先生用：カード、印刷、学習記録、バックアップ、設定。フェイズ別の練習は設定内の折りたたみ欄へ集約。起動時は生徒用の普段使い。生徒用：1枚のカード（Phase 1・2）、複数から選択（Phase 3）、日本語の文づくり（Phase 4〜6）。Phaseや記録件数は生徒用に出さない。設定は長押しと任意PINで誤操作を防ぐ。PINは暗号化ではない。

初期版はタップ操作、文字の表示切替、日本語、静かな配色。選択時の名称読み上げは先生の設定で切り替え（初期値オフ）。録音・ドラッグ・カード複製・配置編集は次段階で検討する。

0.3.0ではPhase 4の文の帯に「よむ／とめる」と「× とりけす」を追加。手動操作時だけ端末内の日本語音声を使い、文を日本語順で読み上げる。外部音声サービスへのフォールバックなし。取消は作成中の文だけを空にし、登録カードと学習記録は保持する。

0.4.0では取消UIを整理。帯のカードそのものをタップするとブックへ戻し、個別の×と左右矢印を廃止。「よむ／とめる」と「↶ ひとつもどす」だけを文の横に置く。直前の操作を取り消す履歴は現在の学習中の100操作まで。受け取り前の提示は戻せるが、受け取り済みの交換記録は取り消さない。

## Phase

| 段階 | 指導で重視すること | 実装状況 |
| --- | --- | --- |
| 1 | 1枚のカードを相手に渡して要求を伝える | 1枚を選んでその場で読み上げ。完了時に未評価の読み上げ記録を保存 |
| 2 | 実際に距離を移動し、相手・場所を変えて伝える | 1枚の画面と段階別の読み上げ記録。環境の距離・相手・場所は先生が調整。画面操作で距離や持続性の達成を判定しない |
| 3 | 複数から欲しい物のカードを選ぶ | 先生が選んだ2枚以上のカードを表示し選択。実物との対応は先生が確認。選択内容の正誤を自動判定しない |
| 4 | Sentence Strip上に物・属性のカードを並べ、要求表現を最後に置いて帯全体を読み上げ | 「ください」の文の基本機能を実装。文末固定、並べ替え、取り消し、文の記録。他の要求表現は今後対応 |
| 5 | 質問に答えて要求する | 質問表示と「ことば＋ください」の文づくり、読み上げ・質問付きの記録 |
| 6 | 質問への応答と自発的なコメント | 質問なし／見る／聞く／持つの設定。「がみえます」「がきこえます」「をもっています」を日本語文末へ。達成・正誤・自発性は自動評価しない |

アプリはPECSの考え方を参考にした教育用の補助であり、正式な指導手順・研修の代替とはしない。Phase 1・2は紙カードと併用できる設計を継続する。

## データ構造

IndexedDB `picture-talk-pecs-v2` の `app` ストア、キー `state` に保存する。単一のreadwriteトランザクションが完了してからメモリー上の状態と画面を更新し、保存失敗時に見かけだけ成功にしない。旧アプリの `ptp_*` localStorageには触れない。

- `schemaVersion`：保存・バックアップの版番号。現在7。旧版1・2・3・4・5・6のカード・設定・記録を保持。旧版1はPhase 1として引き継ぐ。
- `profile`：任意の呼び名、現在の学習カードID、Phase 3の選択肢ID群、Phase 6の学習方法、mode（learning／daily）。初期版は1つの学習設定。
- `cards`：ID、表示文字、カテゴリ、マーク、画像Data URL、共通layout（文字位置と文字サイズ）。
- `records`：ID、日時、Phase、カードID、当時の文字と呼び名、支援の有無。新しい記録はkind=read。kindなしの旧記録は過去の交換として表示。Phase 4〜6は日本語順序のことばの配列、Phase 5・6は質問または質問なしの設定も保持。カードを編集・削除しても過去の意味を保持。
- `settings`：文字表示、PINのsaltとPBKDF2ハッシュ、音声（端末内の声・速さ・間・選択時読み上げ）。
- `lastBackupAt`：書き出し操作日時。ダウンロード完了・外部保存の保証ではない。

呼び名と写真は個人情報になり得る。実名登録は求めず、実データをリポジトリや開発Issueへ含めない。初期版ではメモ・複数の学習者プロフィール・集計グラフは未実装。

## バックアップ

JSONの `format` と `schemaVersion` を確認し、カードID重複、画像URL、記録、PIN設定、総サイズを検証。未知のキーを除去してから内容確認画面を表示する。実行すると現在のデータを一括置換。書き込み失敗時は元のトランザクションを保持する。PIN付きバックアップの復元後は先生用画面をロックする。

ファイルは暗号化しない。端末の「ファイル」や管理下の保存先で保存を確認する。一般公開リポジトリにバックアップを入れない。データ総量を24MBに制限し、25MBの復元上限内で書き出せるようにする。

## PWAと配信

依存のないHTML/CSS/ES Modules。`dist/` を静的HTTPS配信できる。全アセット・manifest・Service WorkerのURLは相対指定。オフラインキャッシュはアプリ本体だけで、画像・学習データはIndexedDBに保存。

Service Workerは必須ファイルの取得が全件成功してからインストールされる。新しい版は開いた画面を強制更新しない。公開時はコード変更に合わせてキャッシュ名を更新する。

第三者CDN、外部フォント、解析、広告、クラウド音声、画像検索、自動同期なし。CSPで配信元以外への通常通信を制限。オンラインの取得・更新時には配信元への通信が発生し、GitHub Pagesを使う際はGitHubのアクセスログがある。CSPは同一配信元の全アプリ間の厳密な分離ではない。

## 今後の保存方式

初期版は小規模利用を対象に、状態一式を保存する。写真や記録が増える段階では画像Blob・カード・セッションを別ストアに分け、保存量・書き込み頻度とバックアップ分割方式を設計し直す。版変更時には既存バックアップの移行を用意する。

## A4印刷（0.6.0）

カードのlayoutを画面・紙で共用。印刷するカードと25・35・45mm角を選び、A4縦の余白10mm内に3mm間隔で並べる。各ページは明示的に分割し、末尾の不要な改ページは入れない。画像のデコードを待って標準印刷画面を開く。印刷対象や用紙サイズの選択はその画面の作業中だけ保持。配置・文字サイズはカードとともにバックアップにも保持する。

## ふだん使い（0.8.0）

フェイズ学習とは別の開始ボタンを設け、黄色いブック・縦のマジックテープ・カテゴリタブ・濃い緑の文カードを表示する。既存カード、配置、音声、バックアップを共用し、カードを複製しない。カテゴリはカードのcategoryから生成し、カテゴリの切り替えでは編集中の文を保持する。要求とコメントの4種の文末を切り替える。ふだん使いの記録は内部phase=0、画面とCSVは「ふだん使い」。正式な学習段階の0を追加する意味ではない。

「おおきい」「ちいさい」は先生がボタンを押したときだけ画像付きの通常カードとして追加。同じ文字の重複を避ける。画像は端末内のCanvasで描画し、画像・文字・配置とともに通常の保存・印刷・バックアップの対象にする。

## 起動と画面遷移（0.9.0）

保存データを読み込んだ後、以前のmodeがlearningでも、カード・フェイズ・PINなどを保持してmodeだけdailyへ変更し、普段使い画面を開く。学習中の文は再起動で空になる。先生用設定はカードブックの「設定」から長押しと任意PINを経て開く。PINは先生用画面の誤操作防止に使い、普段使いを開始する際は求めない。

設定には折りたたみ式の「フェイズ別の練習（1〜6）」を置き、段階・カード・コメント設定と練習開始をまとめる。先生用メニューの「ふだん使いへ」は常に日常モードの新しい文へ戻す。旧home画面は削除し、学習の準備の入口を重複させない。

## 固定マジックテープと配置編集（0.10.0）

settings.bookにrails（4または5）とcolumns（列ごとのカードIDの順序）を保存。全カードは一度だけ所属し、新カードは空きの多い列へ追加、削除済みIDは正規化時に除去する。カテゴリはこの配置から該当カードだけを表示し、空のテープも残す。4本への縮小では溢れた列を4本目の末尾へ移す。保存形式v7とし、旧v1〜v6には4本の初期配置を付与する。

編集フラグはメモリーのみ。本人も明示的な「配置を編集」で変更でき、先生用設定のPINは配置編集には求めない（今回の利用者の指示）。Pointer EventsでiPad・マウスを共用し、10px以上動いたときだけドラッグ、ゴースト表示と移動先の強調、キャンセル時の破棄、直後の誤タップ抑止を行う。画像のブラウザー標準ドラッグは無効。編集時の移動先は列だけ、通常時は文カードだけに制限。編集時の文づくり・読み上げは表示しない。タップして移動先ボタンを選ぶ代替操作を用意する。
