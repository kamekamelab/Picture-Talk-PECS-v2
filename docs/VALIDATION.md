## 自動検証

Node.js v24系、`npm run check` 相当の構文チェックとNode組み込みテスト。

- 交換前・渡す前の受け取り禁止、二重の受け取り禁止。
- 画像・設定・記録のバックアップ生成とパースによる往復。
- 壊れたJSON、形式違い、不正な外部画像URL・SVG、重複ID、存在しない学習カード、未対応Phase・評価の拒否。
- カード削除後も過去のカード名を保持。
- 未知のキーを除去、CSVの引用と数式対策。
- 復元上限を超えるデータ量になる前に保存を拒否。
- Service Workerを隔離環境で実行し、実際の配布ファイルを全取得できること、通信停止時に画面・スクリプトをキャッシュから返すことを確認。
- 別アプリのURLとキャッシュに干渉しないこと、必須素材の取得失敗時はインストールが失敗することを確認。

11テスト合格。Service Workerのテストはブラウザーの実オフライン起動と同等ではない。

## 未確認・検証上の制約

- 内蔵ブラウザーのdownloadイベント待機で応答が停止したため、OS上の保存ファイルは確認できていない。書き出し日時は「保存完了」を保証しない。
- 復元実行時のブラウザー標準confirmで操作が停止した。アプリ内確認に置き換え、ボタンにデータ置換を明記する修正を行った。**修正後の復元完了はブラウザー未確認。**
- 確認ダイアログ停止後はタブ操作もタイムアウト。ネイティブ操作はMacの画面ロックにより使用できなかった。ロック解除を迂回せず、ブラウザー検証を中止。
- 配信サーバー停止後のブラウザー再起動、狭幅、PIN、複数タブ排他、保存容量不足のUIは未確認。
- 実iPad Safari、ホーム画面への追加、機内モード、ファイルアプリでの保存・復元は未確認。
- 通信内容の実ブラウザー監査は未実施。コードとCSPには外部エンドポイント・外部素材・解析SDKを含めていない。

## 残る受入手順

1. ローカル起動し、バックアップをダウンロードして実ファイルを確認する。
2. そのファイルを復元し、カード画像・呼び名・支援記録を再起動後にも確認する。不正なJSONでは現在のデータが保持されることも確認する。
3. キャッシュの準備後、配信停止して再読み込みし、学習・カード編集・保存が使えることを確認する。
4. 390px幅、iPad縦横サイズで、切れ・横はみ出し・押しづらさがないことを確認する。
5. 実iPadではHTTPSの検証用配信先を用意し、インストール・機内モード・画像登録・保存復元を確認する。単なるPCのlocalhost起動でiPad合格としない。

テスト用バックアップ・画像付きの実行時データはGitに登録しない。
