# 利用者と確認した仕様

2026-10-22、日本時間。画面参考：利用者が添付した紙のブック写真とPECSTalkのスクリーンショット。添付画像はリポジトリにコピーせず、構成の参考にする。

## 使い方

- iPad上でカードを選び、音声で伝える使い方を標準にし、紙カードとの併用にも対応する。
- 先生がタップ／ドラッグを選択でき、標準はタップ。現在の実装はタップのみ。
- 生徒は「選ぶ・並べる → よむ」だけで使う。「わたす」「うけとった」の画面や、読み上げ直後の評価入力は表示しない。読み上げ完了を交換成立とは判定せず、読み上げ種別の記録を残す。
- 先生・保護者用の共通編集画面で、一度作った画像と文字を紙・デジタル両方に使う。

## 日本語の文の帯

- 左から右に、日本語として読む順番に並べる。
- 「ください」は最後のカード。「ください」を先に選択しても右端に表示し、後から選ぶカードはその前に入る。
- 例：［ジュース］［ください］、［あかい］［ボール］［ください］。
- 要求表現の先頭固定や、自動的な英語語順への並べ替えは行わない。
- 読み上げは表示と同じ語順を使う。印刷を追加する場合も同じ順序にする。
- 今回の開発版は「ください」の文をタップで作る基本機能。物・属性のカードは最大4枚、要求表現1枚。追加・タップで戻す・選び直し、文の読み上げ、語順を保持した記録・バックアップに対応。
- 「ききたい」「いきたい」など、別の文末表現の編集と選択は今後追加する。

## 文の帯の色と読み上げ・カードを戻す操作

- 台紙は参考写真に寄せた濃いオレンジ色。白いカードとベージュのマジックテープを重ねる。
- 文の横は大きい「よむ」と控えめな「↶ ひとつもどす」に整理する。カード下の×・左右矢印、文の一括取消ボタンは表示しない。
- 完成した文の「よむ」を押すと代わりに読み上げる。再生中は「とめる」になる。選択時の名称読み上げは先生用設定でオン／オフ。初期値オフ、名称読み上げは回数に含めない。
- 読み上げは端末内の日本語音声のみ。言語違い、クラウド、未判定の音声には送らない。準備が必要な場合は先生用に案内。
- 帯のカードをタップするとブックへ戻る。「ひとつもどす」は直前の操作を取り消し、誤って戻したカードも元の位置に戻せる。読み上げ済みの記録・過去の交換記録は取り消さない。カードを変更する際は再生も止める。
- 2026-10-23の確認により、ことばの間を少しあける読み方を初期値とする。読点を入れる方式で、設定で一文としてつなげる読み方にも切り替えられる。話速は標準を初期値とし、先生が声と速さを試聴して選ぶ。
- 読み上げる語順と言葉はカードと同じ。助詞は自動追加しない。高さの変更を「抑揚が増える」と説明しない。実機での自然さの評価は利用者による聞き比べが必要。

## カード作成と印刷（0.6.0で基本機能を実装）

| 設定 | 選択肢 |
| --- | --- |
| 紙カードの実寸 | 大：4.5×4.5cm、中：3.5×3.5cm、小：2.5×2.5cm |
| 文字位置 | 上／下 |
| 文字と画像の比率 | 画像を大きく（文字小）、標準、文字を大きく（画像小）の3種類 |

- 外寸はサイズ選択で決まり、文字と画像の比率を変えても変わらない。
- 写真・イラスト、切り抜き位置、文字、文字位置、比率、枠を共通データとして管理する。
- iPadでは共通のカードデザインを操作しやすい大きさに表示。紙の実寸を画面上の寸法とはみなさない。
- 全体の一括設定とカードごとの設定を設け、紙とiPad両方のプレビューを用意する。
- A4印刷、必要枚数、切り取り線、寸法確認目盛り。印刷は100%を案内する。
- 仮の初期設定は「中3.5cm・文字は上・標準比率」。長い文字の改行や収まりは実寸プレビューで確認できるようにする。

## ブック型の構成（段階的に実装）

先生が決めたカード位置、色・絵・日本語のカテゴリタブ、画面下の文の帯を軸とする。Phase 1・2では情報を絞る。生徒用には管理機能を表示しない。iPad縦横両方で並び順を保つ。

共通レイアウト編集とA4印刷の基本機能を実装。カードごとの文字位置とバランス、印刷対象・サイズの選択、自動改ページに対応。複製枚数・寸法目盛り・切り抜き位置・枠編集、ドラッグ、カテゴリタブ・自由配置は次工程。

## Phase 2・3（0.6.0）

- Phase 2：1枚のカードを自分から使う画面。端末や相手との距離、場所、相手を変える学習は先生が環境を整える。距離の移動を画面タップで代替したとは扱わない。
- Phase 3：先生が2枚以上を指定し、生徒はその中から1枚を選ぶ。選び直しと読み上げに対応。アプリが正解を決めたり、弁別の達成を自動評価したりしない。
- [Pyramid公式のPhase説明](https://pecs-japan.com/絵カード交換式コミュニケーションシステム/)を参照し、今回のデジタル操作と実際の指導目標を区別する。

## Phase 5・6（0.7.0）

Phase 5は先生が「なにがほしいですか？」と問いかける場面で、画面に同じ質問を示す。Phase 6は質問に答える設定（見る・聞く・持つ）と、質問なしでコメントする設定を用意。日本語の助詞を含む文末カード「がみえます」「がきこえます」「をもっています」を最後に置く。質問の自動音声は出さない。学習者が作った文だけを読み上げる。記録には当時の学習方法を残すが、要求の正誤や実際の自発性はアプリで判定しない。
