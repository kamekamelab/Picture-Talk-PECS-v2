# 利用者と確認した仕様

2026-10-22、日本時間。画面参考：利用者が添付した紙のブック写真とPECSTalkのスクリーンショット。添付画像はリポジトリにコピーせず、構成の参考にする。

## 使い方

- iPad上でカードを交換する使い方を標準にし、紙カードとの併用にも対応する。
- 先生がタップ／ドラッグを選択でき、標準はタップ。現在の実装はタップのみ。
- 生徒がカード・文を相手に見せ、相手が受け取る。カード選択だけでは交換成立にしない。
- 先生・保護者用の共通編集画面で、一度作った画像と文字を紙・デジタル両方に使う。

## 日本語の文の帯

- 左から右に、日本語として読む順番に並べる。
- 「ください」は最後のカード。「ください」を先に選択しても右端に表示し、後から選ぶカードはその前に入る。
- 例：［ジュース］［ください］、［あかい］［ボール］［ください］。
- 要求表現の先頭固定や、自動的な英語語順への並べ替えは行わない。
- 読み上げ・印刷を追加する場合も、表示と同じ語順を使う。
- 今回の開発版は「ください」の文をタップで作る基本機能。物・属性のカードは最大4枚、要求表現1枚。追加・取り消し・物／属性の並べ替え、文全体の交換、語順を保持した記録・バックアップに対応。
- 「ききたい」「いきたい」など、別の文末表現の編集と選択は今後追加する。

## カード作成と印刷（実装予定）

| 設定 | 選択肢 |
| --- | --- |
| 紙カードの実寸 | 大：4.5×4.5cm、中：3.5×3.5cm、小：2.5×2.5cm |
| 文字位置 | 上／下 |
| 文字と画像の比率 | 画像を大きく（文字小）、標準、文字を大きく（画像小）の3種類 |

- 外寸はサイズ選択で決まり、文字と画像の比率を変えても変わらない。
- 写真・イラスト、切り抜き位置、文字、文字位置、比率、枠を共通データとして管理する。
- iPadでは共通のカードデザインを操作しやすい大きさに表示。紙の実寸を画面上の寸法とはみなさない。
- 全体の一括設定とカードごとの設定を設け、紙とiPad両方のプレビューを用意する。
- A4印刷、必要枚数、切り取り線、寸法確認目盛り。印刷は100%を案内する。
- 仮の初期設定は「中3.5cm・文字は上・標準比率」。長い文字の改行や収まりは実寸プレビューで確認できるようにする。

## ブック型の構成（段階的に実装）

先生が決めたカード位置、色・絵・日本語のカテゴリタブ、画面下の文の帯を軸とする。Phase 1・2では情報を絞る。生徒用には管理機能を表示しない。iPad縦横両方で並び順を保つ。

印刷、共通レイアウト編集、ドラッグ、カテゴリタブ・自由配置は、この仕様に基づく次工程。基本の日本語文の帯が実装済みであることと区別する。
